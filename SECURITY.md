# Security Policy

## Scope

This policy covers the code in this repository only.  
The upstream [ThemeParks.wiki](https://themeparks.wiki/) API is out of scope — report issues to them directly.

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Use [GitHub Private Vulnerability Reporting](https://github.com/Figaro-Trading/Orlando/security/advisories/new) to submit your report confidentially. Describe the vulnerability and how to reproduce it. If you have a working PoC, include it in the private report.

## Response

This is a community project maintained on a best-effort basis.  
We aim to acknowledge reports within 7 days and provide a fix or mitigation as soon as practical.

## Supported versions

Only the latest version deployed on the `main` branch is supported.
