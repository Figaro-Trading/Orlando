# Code of Conduct

This project adopts the **Contributor Covenant v2.1**.

The full text is available at:  
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainer privately via their [GitHub profile](https://github.com/Figaro-Trading).

## Scope

This code of conduct applies to all project spaces — issues, pull requests, and discussions.
