# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-04-11

### Added
- Real-time wait times for 7 Orlando parks (MK, EPCOT, HS, AK, USF, IOA, Epic Universe)
- Smart "What's next?" recommendation engine with proximity, wait, crowd, and showtime scoring
- 9 day-plan templates with plan-aware suggestions
- GPS auto-detection of current park and land
- Offline-capable PWA with Workbox service worker caching
- WCAG 2.1 AA accessibility (contrast, keyboard nav, screen reader)
- Responsive breakpoints for mobile, tablet, and desktop
- Dark / light / auto theme support
- Lightning Lane Multi/Single (LL-M / LL-S) labels
- Alert banner system for park-specific notices
- GitHub Pages automatic deployment
